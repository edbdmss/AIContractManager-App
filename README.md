# AIContractManager-App
계약의 모든것 모바일 프론트엔드

현재 프론트엔드는 `mobile/`의 React Native + Expo 앱입니다. 개발 환경 설정과 실행 방법은 [모바일 앱 README](mobile/README.md)를 참고하세요.

빠른 시작:

```sh
cd mobile
npm ci
npm run start
```

Android 에뮬레이터에서는 `npm run android`를 사용할 수 있습니다. API 주소, OAuth callback, 기기별 실행 조건은 모바일 앱 README와 `.env.example`을 기준으로 설정합니다.
